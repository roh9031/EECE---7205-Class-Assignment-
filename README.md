Building and Execution
To compile and run any individual problem source file using g++:
# Navigate to the source folder
cd Class_Assignment_1_Bidnurmath/src

# Compile a specific problem file
g++ -O2 Class_Assignment_1_problem7_Bidnurmath.cpp -o Class_Assignment_1_problem7_Bidnurmath.exe

.\Class_Assignment_1_problem7_Bidnurmath.exe
